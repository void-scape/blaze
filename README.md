# Blaze

Simple *no_std* libraries for game development in Rust.

Library | Category | Description
------- | -------- | -----------
frend | Graphics | truetype font rasterizer
rast | Graphics | rasterize primitives shapes into a frame buffer
tint | Graphics | color space conversions
lidsp | Audio | minimal DSP library
packit | Assets | trait for reading and writing assets into a byte buffer
glazer | Platform | generic platform layer providing a frame buffer, sample buffer, and system input
